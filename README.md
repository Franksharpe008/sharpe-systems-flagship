# Sharpe Systems Flagship

Live URL: `https://sharpe-systems-flagship.vercel.app/`

Sharpe Systems is a premium flagship site for repositioning weak business fronts into clearer, higher-trust operating systems.

## What the site does

- frames the business around authority, proof, and follow-through
- uses a living hero surface instead of a static banner
- routes visitors into a diagnostic instead of a dead-end contact form
- keeps the public-facing story focused on outcomes, not production process

## Sections

- Hero
- Transformation
- Operating lanes
- Proof ledger
- Engagement lanes
- Diagnostic

## Local commands

```bash
npm install
npm run dev
npm run build
```
